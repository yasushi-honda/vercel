# 組織図と目的

組織図と目的を表示するインタラクティブなWebアプリケーションです。

## 概要

このプロジェクトは、組織の部門構成と責任者を明確化し、チームメンバー間のコミュニケーションを改善することを目的としています。

## 技術スタック

- **Vue.js 3** - JavaScriptフレームワーク
- **Tailwind CSS** - スタイリング
- **Remixicon** - アイコンライブラリ

## 機能

### 1. 目的ビュー
組織・責任者を明確化する3つの目的を表示：
- タダメンのペイン解消
- タダメンの横のコミュニケーション強化
- マネジメントメンバーのタスクシフト

### 2. 組織図ビュー
11の部門・室の詳細情報を表示：
- 法人経営室
- 会計・監査・税務室
- 広報・マーケティング室
- ファンドレイジング室
- ICT研修企画室
- 人財育成室
- ICT講師派遣事務局
- コミュニティマネジメント室
- 生成AI研究所
- 情報システム部
- 事業開発室

各部門には、外部向け名称、管掌者、機能・役割、メンバーリスト、詳細説明が含まれます。

## 使い方

1. ブラウザで `index.html` を開く
2. 「目的」と「組織図」のタブを切り替えて表示
3. 組織図ビューでは、各部門をクリックして詳細を展開・折りたたみ

## Serena MCP設定

このプロジェクトには、AI開発をサポートするSerena MCPサーバーが設定されています。

### Serena MCPとは？

Serena MCPは、セマンティックコード検索と編集機能を提供するAIコーディングエージェントツールキットです。以下の機能を提供します：

- コードベース全体のセマンティック検索
- インテリジェントなコード編集支援
- Language Server Protocol (LSP) との統合
- Claude Codeやその他のAIツールとのシームレスな連携

### セットアップ

Serena MCPの設定は `.claude/mcp.json` に定義されています。

Claude Codeを使用している場合、このMCPサーバーは自動的に検出され、利用可能になります。

### 必要な環境

- Node.js (npxが使用可能な環境)
- インターネット接続（初回実行時に @oraios/serena パッケージをダウンロード）

### 詳細情報

Serenaについての詳細は以下を参照：
- GitHub: oraios/serena
- MCP統合により、より高度なコード分析と編集が可能
